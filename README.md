# modularize

Decompose or reconcile bounded material into coherent modules with explicit source accounting, stable identities, and residual uncertainty.

## Use

> Modularize this inventory by its natural joints and account for every constituent.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `modularize/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
